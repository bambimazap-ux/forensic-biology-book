# Forensic Biological Identification: From DNA to Fingerprints
### Interactive Curriculum & Reference Archive

An executive-grade, mobile-responsive interactive digital book and curriculum reader developed for forensic biology practitioners, researchers, and students.

**Division of Identification and Forensic Science (DIFS / מז"פ) • R&D Section (מדור מו"פ)**

---

## 🌟 Key Features

- **Interactive Reader Experience:** Clean typography with full support for Light, Dark, and Sepia reading themes, font size scaling, reading progress tracking, and sidebar chapter navigation.
- **Mobile-First Responsive Design:** Fully optimized for smartphones, tablets, and desktop workstations with collapsible touch drawer, touch-friendly pill badges, and mobile-friendly overlays.
- **Unified Forensic Glossary:** 301 curated forensic concepts cross-linked throughout all 13 chapters with interactive popover definitions and deep links to Appendix A.
- **High-Resolution Figures (62 Figures):** Dual vector SVG and 300 DPI print-quality figures embedded directly in the text with an interactive fullscreen Lightbox viewer and zoom tools.
- **Master References & PDF Archive:** 379 academic references with clear visual differentiation between local offline papers (emerald badges 📄) and online DOI links (sky blue badges 🌐), complete with instant search and filtering.
- **100% Offline Capability:** Standalone client-side architecture with zero external CDN dependencies.
