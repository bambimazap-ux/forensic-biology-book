# Appendix A. Unified Glossary — Forensic Biological Identification: From DNA to Fingerprints

This glossary consolidates key terms from Chapters 0–12. Entries are arranged alphabetically by their English term; recurring concepts appear once, with chapter-specific uses combined where appropriate.

| Term | Definition |
|:---|:---|
| Absolute identification | In Prof. Joseph Almog’s course terminology, determining the identity or class of a substance rather than comparing it with a reference source. |
| ACE output categories | The primary examiner’s categorical responses—identification, inconclusive, and exclusion—that can be calibrated against known same-source and different-source comparisons \[Mor24b\]. |
| ACE-V | Analysis, Comparison, Evaluation, and Verification: a structured workflow for fingerprint examination \[Dal18\]. |
| Acid phosphatase (AP) | An enzyme abundant in seminal plasma whose activity is used as a presumptive semen test; activity alone does not establish that a sample is semen \[Gam20\]. |
| Activity-level proposition | A claim about the activity that may have deposited biological material, evaluated against an alternative activity rather than only an alternative contributor \[Coo98, Gil20\]. |
| Admissibility | A court’s decision about whether expert evidence may be received in legal proceedings \[Edm14\]. |
| Admixture | Estimated genetic contributions relative to the groups represented in a particular model; it is not a literal family tree \[Law18\]. |
| Adventitious match | A coincidental profile association among people unrelated to the source of a forensic trace \[Wei04\]. |
| AFIS and ABIS | Automated fingerprint identification systems and broader automated biometric identification systems that search enrolled records and return candidates for review; retrieval is distinct from examiner comparison and source conclusions \[Mal17, Sin20c\]. |
| AFIS-selection bias | Bias in a latent-print test set arising when the tested latents were previously identified through AFIS, potentially excluding harder unsuccessful searches and overstating performance on difficult casework \[Ind09\]. |
| Allele drop-in | Detection of an allele signal not accounted for by the assumed profile, as defined and modelled in forensic STR interpretation \[Gil12, Gil15\]. |
| Allele drop-out | Failure to detect an allele that is present in the sample, a possibility that becomes important in low-template interpretation \[Gil12, Gil15\]. |
| Allele-frequency database | A curated reference collection used to estimate allele frequencies for a sampled population \[Bud01b, Bod16\]. |
| Allele-frequency difference (δ) | A measure of allele-frequency contrast between a specified pair of populations \[Ros03\]. |
| Allele-frequency differentiation | Differences in allele frequencies among sampled populations that can carry information about population structure \[Job22, Tve22\]. |
| Allele sharing | The presence of the same allele in multiple contributors, which can conceal mixture complexity \[Cla98, Gil06\]. |
| Allelic ladder | A reference mixture of characterized alleles used to assign STR allele designations by comparison with sample fragments \[But12b, Mor01\]. |
| Alpha-amylase | A starch-digesting enzyme whose activity is commonly used to screen for saliva, although activity is not unique to saliva \[Wor18\]. |
| Alternative light source (ALS) | Illumination used to locate or map possible stains; it does not by itself identify a body fluid \[Sij21\]. |
| Amelogenin marker | A length-polymorphic marker targeting AMELX and AMELY; its result is not a definitive determination of sex or sex-chromosome complement \[But14\]. |
| Amino-acid reagents | Fingermark-development reagents such as ninhydrin, DFO, and 1,2-indanedione that react with amino-acid components and produce visible or luminescent signals \[Jel09b\]. |
| Analytical threshold | A laboratory-validated signal level used to distinguish candidate STR peaks from background noise \[Bre13b, Sci21\]. |
| Ancestry-informative marker (AIM) | A genetic marker selected to differentiate specified comparison populations; its usefulness depends on the populations and task \[Ros03, Kid14\]. |
| Arch, loop, and whorl | Broad classes describing the overall flow and arrangement of fingertip friction ridges \[Glo23, Li22\]. |
| Area under the curve (AUC) | A model-level measure of discrimination across decision thresholds; it is not an individual’s probability of having a predicted trait \[Sch19\]. |
| Background DNA | DNA already present or deposited through activities other than the disputed activity \[Tay21, Gil20\]. |
| Balding–Nichols model | A population-structure model that adjusts genotype probabilities using the coancestry parameter θ \[Bal94\]. |
| Bayes factor | A ratio comparing the probability of observed data under two propositions; it is not the probability that either proposition is true \[Mor24b\]. |
| Bayesian estimation | Estimation that combines a likelihood with prior distributions to represent and integrate uncertainty in model parameters \[Gil21c\]. |
| Bayesian network | A probabilistic structure representing dependencies among observations, propositions, activities, or transfer pathways under stated assumptions \[Sam22, Tay18b, Sam20\]. |
| Biogeographical ancestry (BGA) | A model-based comparison of genetic variation with specified population reference data, used as investigative intelligence rather than as a claim of identity \[Tve22, Kay23b\]. |
| Bisulfite conversion | Chemical treatment that produces different sequence-read outcomes for methylated and unmethylated cytosines and can also reduce or fragment DNA \[Nau23b, Vid18\]. |
| Black-box and white-box studies | Black-box studies measure examiner decisions against known-source comparisons; white-box studies also record annotations or aspects of the decision process \[Ule11, Ule14\]. |
| Calibration | Assessment of whether model outputs behave as expected on relevant known-sample data \[Bri15b, But24b\]. |
| Candidate list | The ranked records returned by an automated search for examiner review; list membership is a retrieval outcome, not a source conclusion \[Tay12, Bec22\]. |
| Candidate rank and similarity score | Outputs that order candidates under a matcher and search setup; they are not, by themselves, likelihood ratios, error probabilities, or source conclusions \[Swo18b, Neu20c\]. AFIS scores are proprietary similarity scores, and examiner use varies \[Tay12\]. |
| Capillary electrophoresis (CE) | Separation and fluorescent detection of DNA fragments as they migrate through a polymer-filled capillary \[But12b, She12\]. |
| Capture-based sequencing | Enrichment of target DNA fragments from a prepared library using complementary probes before sequencing \[Tem13\]. |
| Case-specific data | Data whose participants, materials, contact histories, sampling, or analytical methods are relevant to the circumstances being evaluated \[Tay18, Gil20\]. |
| Catalytic test | A test that detects a chemical reaction accelerated by a catalyst, such as heme-associated activity in blood screening \[Tob07\]. |
| Cell composition | The proportions of cell types in a bulk sample, which can shift its average DNA-methylation measurement \[Vid18, Nau23b\]. |
| Centimorgan (cM) | A genetic-map measure of recombination distance used to summarize shared genomic-segment lengths in genealogy matching \[Huf11, Kli21\]. |
| Chain of custody | Documentation of an exhibit’s identity, handling, and transfers from collection through analysis \[But22\]. |
| Classification uncertainty | Uncertainty arising from reference coverage, marker data, model assumptions, or competing plausible ancestry assignments \[Tve22, Per20\]. |
| Chemiluminescence | Light emitted during a chemical reaction, as in luminol visualization of possible bloodstains \[Bar07\]. |
| Chronological-age marker | A methylation marker selected to predict time since birth, distinct from a measure intended to represent biological aging \[Nau23b\]. |
| Cline | A gradual geographic change in genetic variation or allele frequencies \[Ser04\]. |
| Coancestry coefficient θ | A parameter representing population-level correlation associated with shared ancestry under a defined population comparison \[Bal94, Bal05b\]. |
| CODIS | The U.S. software and network connecting local and state DNA database systems with the national tier \[But12d\]. |
| CODIS core loci | The autosomal STR marker set used to support profile comparison within the U.S. DNA database system \[But06c\]. |
| Cognitive bias | The influence of expectations, context, or prior judgments on professional decision-making \[Coo19\]. |
| Cold hit | A database match that may provide a previously unknown investigative lead \[Ama19, Ama21\]. |
| Combined probability of exclusion (CPE) | The complement of the combined probability of inclusion across the loci considered \[Bie16f\]. |
| Combined probability of inclusion (CPI) | A mixture inclusion summary combining allele-inclusion probabilities across loci \[Bie16f\]. |
| Comparative identification | In Prof. Joseph Almog’s course terminology, comparing a questioned trace with a reference item to assess correspondence or a possible source relationship. |
| Conclusion scale | The set of categories or support statements used to report an examination; its meaning depends on definitions, thresholds, and validation \[Bec20, Bec22\]. |
| Conditioning on a known contributor | Explicitly assuming that a person with a known profile contributed, in order to constrain possible genotype combinations in a mixture \[Cla98, Gil06\]. |
| Confirmatory test | A test that supports a defined claim about a target within the method’s validated scope \[Cut24\]. |
| Contamination control | Laboratory safeguards such as separated work areas, blanks, controls, review, and proficiency testing used to detect or reduce unintended DNA contributions \[Par14c, Grz18\]. |
| Continuous model | A probabilistic-genotyping approach that uses quantitative peak-height information when evaluating possible genotype configurations \[Cow07, Gil21c\]. |
| Control region | The non-coding mitochondrial DNA region containing regulatory elements and sequence variation used in forensic comparison \[Cou21b, Amo19b\]. |
| Correspondence | Observed agreement or similarity between questioned and known features under the criteria of an examination; it is distinct from a source conclusion \[Sak08, Bec20, Ule14\]. |
| Counting method | A haplotype-frequency estimate based on exact matches observed in a selected reference sample \[Roe20\]. |
| CpG site | A genomic position where cytosine is followed by guanine, a common context for measuring DNA methylation \[Nau23b, Vid18\]. |
| Criminalistics | The study and interpretation of physical evidence, traditionally focused on linking traces with sources and activities \[Kir63, Bur13\]. |
| Criminology | The study of crime as a social phenomenon, including its causes, patterns, and prevention \[Bur13\]. |
| Cross-reactivity | A positive test response caused by non-target material, although the sample may also contain traces of the target \[Str23b\]. |
| Cross-validation | Repeated evaluation on withheld portions of development data; it does not replace testing a fixed model on independent samples \[Nau23b, Ref23\]. |
| Cyanoacrylate fuming | A process in which cyanoacrylate vapor polymerizes along residue-bearing ridges on a nonporous item \[War07\]. |
| Database search problem | The evaluation of a match selected by searching database records, rather than a comparison begun with a named person \[Mee19\]. |
| Database mixture search | A search that uses mixture-profile information to rank candidate records, with retrieval dependent on the model, threshold, and validation conditions \[Ben17c, Noz24\]. |
| Decision-based interpretation | Selection of the evaluation and reporting method according to the case question and suitability of the available Y-STR data \[Roe20\]. |
| Deconvolution | Identification of possible contributor genotype combinations that could explain an observed DNA mixture \[Cla98, Gil06\]. |
| Degradation index | An assay-specific comparison of short- and long-target amplification used as an indirect indicator of DNA fragmentation \[Hud08, Ewi16\]. |
| Deletion | Removal of a DNA profile from searchable database records under applicable rules \[Ama18\]. |
| Developmental validation | Evaluation of an assay’s analytical performance and intended-use limits under relevant specimens and conditions \[Nau23b, Ref23\]. |
| Differential extraction | A procedure that separates sample fractions to enrich sperm-cell DNA relative to non-sperm DNA, without guaranteeing pure fractions \[Vui11, Cla21\]. |
| Direct STR confirmation | Comparison of a candidate’s STR profile with an evidentiary profile to assess DNA-source correspondence after a FIGG lead \[Gue21, Til21b\]. |
| Direct-to-consumer (DTC) genealogy database | A consumer genealogy service whose user-submitted genetic data may be available for matching under platform-specific rules and settings \[Kli21, Gue21\]. |
| Direct transfer | Movement of biological material from a person or source to an item through direct contact \[Tay18, Oor19\]. |
| Disaster victim identification (DVI) | Identification of victims using genetic evidence and other specified information, including joint pedigree-based evaluations \[Pri07, Vig21\]. |
| Discrete Laplace method | A Y-STR haplotype-frequency estimation approach that uses repeat-step relationships among haplotypes as well as exact recurrence \[And13\]. |
| DNA contamination | Unintended introduction of foreign DNA during evidence collection, handling, or laboratory processing \[Oor15, Bas18\]. |
| DNA fingerprinting | Early DNA profiling based on variable patterns in repetitive DNA regions \[Job13, Roe13\]. |
| DNA methylation | Addition of a methyl group to DNA, measured at selected sites without changing the underlying base sequence \[Nau23b, Vid18\]. |
| DNA methylation marker | A selected methylation site or pattern investigated for distinguishing cell types, body fluids, age, or exposure within a defined assay and model \[For16, Nau23b\]. |
| DNA mixture | A biological sample containing DNA from more than one contributor \[Cla98, Gil06\]. |
| DNA profile | A set of genetic-marker results derived from a sample for comparison or further interpretation \[Had21\]. |
| Eccrine and sebaceous contributions | Eccrine secretion contributes an aqueous fraction and solutes; sebaceous material contributes lipids and may reach fingers through contact \[Rob22, Bec26d\]. |
| Effective allele number | A measure of genetic diversity that does not necessarily indicate between-population discrimination \[Che19e\]. |
| Electropherogram | A processed display of fluorescent signal against fragment size or migration, including detected peaks and analytical labels \[Sci21\]. |
| ELFT-EFS | A NIST evaluation testing matchers’ use of standardized examiner-marked extended fingermark features, in image-plus-feature and feature-without-image search conditions \[Ind11\]. |
| ELFT Phase II | A NIST evaluation of automated latent feature extraction and one-to-many searches; its previously AFIS-identified latent set created selection bias \[Ind09\]. |
| Elimination DNA database | A reference collection of profiles from personnel or others who may legitimately encounter evidence, used to investigate potential contamination \[Nog25\]. |
| EMPOP | The EDNAP mitochondrial DNA Population Database, a curated forensic resource for searching mtDNA haplotypes in population data \[Par07c\]. |
| Epigenetic clock | A model that combines methylation measurements to estimate age within its validated scope \[Nau23b, Ref23\]. |
| Epigenetic drift | Increasing dispersion of methylation values between individuals at many sites with age \[Han12b\]. |
| Error-rate denominator | The defined set of decisions or trials over which false-positive or false-negative outcomes are counted; handling inconclusive and no-value outcomes changes the question answered \[Ule11, Rob24\]. |
| European Standard Set (ESS) | A shared STR marker set intended to support DNA-profile comparison across European systems \[But06c, But12e\]. |
| Examiner–algorithm hand-off | The documented transition from automated candidate retrieval to examiner comparison, keeping system outputs distinct from human findings \[Tay12\]. |
| Exclusion | A categorical conclusion that the observed comparison does not support the specified source relationship, subject to the method and information available \[Bec20, Mor24b\]. |
| Exposure classifier | A model that classifies methylation patterns associated with an exposure in a defined study population and assay context \[Maa19\]. |
| Extended feature set (EFS) | A standardized set of examiner-marked ridge features supplied to fingerprint matchers for evaluation \[Ind11\]. |
| Externally visible characteristic (EVC) | A selected visible trait, such as pigmentation, for which a genetic model may return category probabilities \[Cha18, Ter24\]. |
| Extraction efficiency | The proportion of collected material released from a swab into the extraction solution \[Bru24b\]. |
| False positive and false negative | A positive test result without the target, or a negative result when the target is present, respectively \[Mor21b\]. |
| Familial searching | A deliberate database search that ranks possible biological relatives of an unknown-source profile as investigative leads \[Piq19, Ge20\]. |
| FIGG program oversight | Review and accountability measures, such as technical review, complaint routes, and program reporting, recommended for responsible practice \[Wic23b, Wic25\]. |
| Finite-sample uncertainty | Variation in estimated allele frequencies or profile probabilities arising from use of a finite reference sample \[Cur02, Cur05\]. |
| Fisher information | A measure related to the precision of estimated ancestry contributions, dependent on frequency contrasts, proportions, and population diversity \[Pfa04\]. |
| Fixed feature-count rule | A conclusion rule requiring a specified number of corresponding fingerprint features; a count is not a universal measure of evidential significance \[Bec22\]. |
| Forensic DNA intelligence (investigative intelligence) | Genetic or other forensic information used to guide investigative follow-up without, by itself, establishing identity or activity \[Pou26, Scu19c, Vid18, Nau23b\]. |
| Forensic investigative genetic genealogy (FIGG) | A process that uses forensic DNA data and genealogy-database matches to generate investigative leads, not to establish identity \[Kli21, Gue21\]. |
| Forensic science | Case-based scientific inquiry into traces of past activity and their significance for investigation and legal decision-making \[Rou12, Rou22\]. |
| Forensic serology | Examination of biological stains using blood groups and other biological markers \[Job13\]. |
| Forensic-trace profile | A DNA profile developed from crime-scene material whose source is initially unknown \[But12d\]. |
| Forensic vacuum metal deposition (fVMD) | A specialist metal-deposition method for difficult surfaces whose contrast-producing mechanism remains unsettled \[Dov25\]. |
| Foundational validity | Empirical support that a method performs as claimed under studied conditions; it does not establish validity as applied in a particular case \[Scu23, Cor16\]. |
| FpVTE | NIST’s Fingerprint Vendor Technology Evaluation, which tested fingerprint matching and identification systems on defined datasets \[Wil04e\]. |
| Friction-ridge skin | Skin on the volar surfaces of the fingers, palms, toes, and soles, with raised ridges and associated structures \[Mac09, Glo23\]. |
| FST | A summary measure of genetic differentiation among populations, not the precision of an individual ancestry estimate \[Che19e\]. |
| Full match | Agreement between profiles at the loci available for comparison under a system’s matching rules \[But12d\]. |
| Genealogical hypothesis | A revisable family-tree explanation assessed against genetic matches and documentary records \[Kli21, Gre19\]. |
| Genotype frequency | The probability assigned to a genotype under a specified allele-frequency and population model \[For03, Bal94\]. |
| Genotype imputation | Estimation of untyped or missing genotypes from observed data and reference panels, with uncertainty dependent on data and panel suitability \[Kli21\]. |
| Glycophorin A | A red-cell membrane protein targeted by the RSID-Blood assay \[Cut24\]. |
| Graphical-model estimator | A Y-STR haplotype-frequency approach that models dependencies among loci, including pairwise or higher-order relationships \[And18b, And19\]. |
| Haplogroup | A branch of a paternal Y-chromosome or maternal mitochondrial phylogeny defined by shared derived mutations \[Cou21, Kni22, Par14c\]. |
| Haplotype frequency | The estimated occurrence of a linked-marker haplotype in specified population data, subject to sampling and database limitations \[Par14c, Buc11, Roe20\]. |
| Hardy–Weinberg equilibrium (HWE) | A population-genetic model relating allele frequencies to genotype probabilities \[For03, Bal94\]. |
| Heterozygote balance | The relative signal strength of the two alleles observed at a heterozygous STR locus \[Lec04, Sci21\]. |
| Hierarchy of propositions | The distinction between sub-source, source, activity, and offence-level questions; a conclusion at one level does not by itself answer a higher-level question \[Coo98, Gil20\]. |
| Hit rate | A database performance measure relating profile matches to a stated denominator, commonly loaded crime-scene profiles \[Ama19, Ama21\]. |
| Hit/no-hit exchange | An initial cross-border DNA query that reports whether a candidate match is present before follow-up information is requested \[Ama19c, Too19\]. |
| Hook effect | A false-negative or weakened immunoassay result that can occur when excessive antigen interferes with test-line formation \[Cut24\]. |
| Human hemoglobin (hHb) | Hemoglobin targeted by most forensic immunochromatographic blood tests \[Cut24\]. |
| HVS-I and HVS-II | Hypervariable segments of the mitochondrial control region commonly used as forensic sequence targets \[Cou21b, Tem13\]. |
| Hybridization capture | Enrichment of selected library fragments with complementary probes before sequencing \[Gor20, Wat25d\]. |
| Identity by descent (IBD) | Sharing of a genetic variant or genomic segment because it was inherited from a shared ancestor \[Kni22, Huf11\]. |
| Identity by state (IBS) | Sharing of an observed genetic state without establishing inheritance from a recent shared ancestor \[Kni22\]. |
| Immunochromatographic assay | A lateral-flow test that uses antibody–antigen binding to detect a defined target \[Cut24\]. |
| Inclusion | The rule-based admission of a profile to a forensic DNA database \[San13b\]. |
| Inconclusive result | A report outcome used when validated criteria do not support assigning a sample or comparison to a defined class \[Sil16, Ger24, Bec20\]. |
| Independent test set | Samples not used to select markers or fit a model, used to assess performance beyond the development data \[Nau23b, Ref23\]. |
| Individualization | A categorical inference that a trace came from one source to the exclusion of all others \[Sak08, Col09\]. |
| Informativeness for assignment (Iₙ) | A measure of how much allele-frequency patterns reduce uncertainty about population assignment across a chosen comparison set \[Ros03\]. |
| Interlaboratory variation | Differences among laboratories’ decisions or measurements for the same or comparable data \[Hic23, But18\]. |
| Internal PCR control (IPC) | A control template included in a qPCR reaction to help detect reduced amplification efficiency, including possible inhibition \[Hud08, Ewi16\]. |
| Internal size standard | Reference fragments added to a sample to estimate fragment sizes within a capillary-electrophoresis run \[But12b\]. |
| Investigative lead | Information that directs follow-up but does not by itself establish source identity or resolve an offence \[But12d, Gue21, Scu19c\]. |
| ISO/IEC 17025 | An international standard for competence and quality management in testing and calibration laboratories \[Neu23\]. |
| Isoalleles | STR alleles with different DNA sequences but the same measured fragment length \[Par16, Alo18\]. |
| Kappa estimator | A Y-STR frequency-estimation approach that adjusts rare-haplotype counts using features of the reference database \[Roe20\]. |
| Kinship index | A likelihood ratio comparing genetic findings under a specified relationship with findings under an unrelated-person proposition \[Kim11c, Ge20\]. |
| Kirk’s individuality principle | The historical claim that objects are unique; uniqueness alone does not prove that a method can identify a single source \[Kir63, Sak08\]. |
| Known-person profile | A DNA reference profile linked to an identified person \[But12d\]. |
| Latent fingermark residue | Transferred material that may be difficult to see and whose composition varies with secretion, contact, deposition, substrate, and later change \[Bec26d, Rob22\]. |
| Length heteroplasmy | Coexistence of mitochondrial DNA molecules that differ in repeat length, often in control-region homopolymers \[Par14c, Stu19\]. |
| Likelihood or Bayesian classification | Methods that compare a profile with specified reference groups, with results conditional on those groups and the model \[Tve22, Mog19\]. |
| Likelihood ratio (LR) | The ratio comparing the probability of the same evidence under two specified competing propositions; it is not the probability that either proposition is true \[Eve15, Gil18\]. |
| Lineage evidence | Genetic evidence supporting correspondence to a paternal or maternal line without necessarily identifying one individual \[Roe20, And21b, Buc11\]. |
| Linear Sequential Unmasking (LSU) and LSU-E | Procedures for sequencing contextual information so an examiner can document an initial trace assessment and manage exposure to potentially biasing information \[Dro15, Dro21\]. |
| Linkage equilibrium | The assumption that loci are sufficiently independent for multilocus genotype probabilities to be combined \[For03, Bal94\]. |
| Locard’s exchange principle | Contact or activity may transfer traces between people, objects, and environments \[Rou22\]. |
| Major contributor | A contributor represented by a relatively greater signal in a DNA mixture profile \[Gil98b, Cla98\]. |
| Male-specific region of the Y chromosome (MSY) | The largely non-recombining region of the Y chromosome that contains most forensic Y-STR loci \[Cou21\]. |
| Markov chain Monte Carlo (MCMC) | A computational sampling method used to integrate over uncertain parameters in Bayesian probabilistic-genotyping systems \[Gil21c\]. |
| Massively parallel sequencing (MPS) | Parallel sequencing of many targeted DNA regions, providing sequence information in addition to fragment length or other marker measurements \[Bru18, Had21\]. |
| Maternal inheritance | The usual transmission of mitochondrial DNA from mothers to their children, causing variants to be shared along maternal lines \[Amo19b, Cou21b\]. |
| Maternal-lineage match | A correspondence between mitochondrial DNA profiles that supports a shared maternal lineage but does not uniquely identify one person \[Amo19b, Buc11\]. |
| Maximum allele count (MAC) | The greatest number of distinct alleles observed at any one locus, used as a lower bound on the number of contributors in a mixture \[Pao05, Han11\]. |
| Maximum-likelihood estimation | An approach that estimates model parameters by maximizing the likelihood of observed data \[Gil21c\]. |
| Mean absolute error (MAE) | The average absolute difference between predicted and observed values in an evaluation set; it is not an individual prediction interval \[Nau23b, Ref23\]. |
| Messenger RNA (mRNA) profiling | Classification of biological material using patterns of expressed RNA markers \[Ing18\]. |
| Methylation-sensitive restriction-enzyme assay | An assay that infers methylation from enzyme cleavage at selected recognition sites rather than measuring each CpG base directly \[Vid18\]. |
| Microbiome signature | A microbial-community pattern studied as a marker of body site or biological material \[Swa25\]. |
| MicroRNA (miRNA) | A class of small RNA molecules explored as markers for body-fluid classification \[Sak20\]. |
| Minimum allele-frequency floor | A lower bound used to avoid assigning zero frequency to rare or unobserved alleles, subject to model assumptions \[Cur05, Bod16\]. |
| Minor contributor | A contributor represented by a relatively weaker signal in a DNA mixture profile \[Gil98b, Cla98\]. |
| Minutia | A local friction-ridge configuration, such as a ridge ending or bifurcation \[Wer02, Bec20\]. |
| Missing-person identification | Evaluation of whether remains occupy a specified position in a family pedigree against an explicit alternative \[Ge10\]. |
| Missing-person identification using mitochondrial DNA | Use of a comparison with maternal relatives to support a lineage association when direct or nuclear DNA references are limited \[Amo19b, Cou21b\]. |
| Mitochondrial genome (mitogenome) | The compact, circular DNA genome outside the nuclear chromosomes, containing genes for mitochondrial function and a non-coding control region \[Cou21b, Amo19b\]. |
| Mitochondrial likelihood ratio | A comparison of the probability of mitochondrial DNA findings under competing propositions, informed by haplotype data and assumptions about population and relatedness \[Par14c, Buc11\]. |
| Mixture likelihood ratio | A likelihood ratio comparing the probability of an interpreted mixture under competing contributor propositions \[Gil06, Gil18\]. |
| Mixture proportion | An approximate estimate of the relative signal attributed to a contributor or component \[Gil98b, Cla98\]. |
| Moderate-stringency search | A DNA database search using less restrictive matching criteria to return candidate profiles that do not meet full-match criteria \[Piq19, Wei04\]. |
| Multilocus profile frequency | A model-based probability for a genotype profile across loci, conditional on frequency data and independence assumptions \[For03, But24b\]. |
| Multiplex PCR | Amplification of multiple target regions in one reaction using multiple primer pairs \[But12f\]. |
| National DNA Database (NDNAD) | The United Kingdom’s national collection of forensic DNA profiles \[But12d, Ama19c\]. |
| National DNA Index System (NDIS) | The national tier of the U.S. CODIS architecture \[But12d\]. |
| National forensic DNA database | A searchable system of DNA-profile records used to compare person and forensic-trace profiles and support investigation \[Ge14b, But12d\]. |
| Negative predictive value (NPV) | The reliability of a negative category call in a specified validation setting \[Sch19\]. |
| Non-recombining region | A chromosome region not routinely exchanged with its counterpart during meiosis; the MSY is largely non-recombining with the X chromosome \[Cou21\]. |
| NRC II recommendations | Historical recommendations addressing population structure in forensic DNA evaluation, including an adjustment for certain apparent single-band results \[Eva97, Bal94\]. |
| Nuclear mitochondrial DNA segment (NUMT) | A mitochondrial-like sequence embedded in nuclear DNA that can be mistaken for mitochondrial DNA in analysis \[Mar21d, Car26b\]. |
| Number of contributors (NoC) | An estimate of how many people are represented in a DNA mixture profile \[Pao05, Han11, Hic23\]. |
| Numerical and verbal reporting | Communication of a likelihood ratio and, where appropriate, a verbal expression of evidential weight while preserving propositions, assumptions, and limits \[Mea20, Buc25\]. |
| Off-scale peak | An STR peak exceeding the detector’s linear range, making its displayed height an unreliable measure of signal \[Sci21\]. |
| Operational validation | Evaluation of the full intended capability, including markers, reference data, laboratory process, analysis, and relevant casework conditions \[Pou26\]. |
| Opt-in and opt-out matching | Platform settings that determine whether a genealogy-database user’s profile is available for law-enforcement matching, subject to provider rules \[Kli21, Gue21, Ske20\]. |
| Outlier or rejection test | A procedure that permits an ancestry assignment to be withheld when a profile fits no available reference well or remains ambiguous \[Mog19\]. |
| Oversight | Independent review of database governance, safeguards, and proposed new uses \[Ube24\]. |
| Partial match | An incomplete allele-level correspondence between profiles that may prompt review but does not establish contribution or relationship \[Piq19, Wei04\]. |
| Paternal lineage | A line of descent traced through successive father-to-son transmissions \[Kay17c, Cou21\]. |
| Paternal-relative sharing | The possibility that men related through a paternal line carry the same or a closely related Y-STR haplotype \[Kay17c, Roe20\]. |
| Paternity index (PI) | A relationship likelihood ratio comparing paternity by a tested man with paternity by a specified alternative, commonly an unrelated man \[Mor02, Gje07\]. |
| PCR | An enzymatic method for amplifying selected DNA regions \[But15\]. |
| PCR inhibitor | A substance in an extract that reduces or prevents amplification by interfering with the PCR reaction \[Ala12\]. |
| Peak-height model | A statistical representation of quantitative electropherogram signal used by continuous probabilistic-genotyping methods \[Cow07, Cow13\]. |
| Pedigree likelihood ratio | A comparison of genetic findings under competing family-relationship structures \[Ge10, Ege00\]. |
| Permanence and persistence | Permanence concerns stability of features on the skin; persistence concerns whether impressions remain sufficiently similar across time and capture conditions \[Mon19\]. |
| Phylogenetic alignment | Sequence alignment guided by harmonized conventions and evolutionary relationships to represent variants consistently \[Par14c, Ban06\]. |
| PhyloTree | A curated framework of mitochondrial haplogroup motifs and relationships used in phylogenetic interpretation \[Par14c, Hub18, Dur21\]. |
| Physical developer (PD) | A silver-based redox process that deposits metallic silver on residue components and is used on selected porous items \[Sod16, Bec20\]. |
| Point heteroplasmy | Coexistence of different nucleotide variants at one mitochondrial DNA position \[Par14c, Stu19\]. |
| Population identifiability | The context-dependent potential to narrow a person’s identity through genetic-match availability together with demographic clues and genealogical records \[Erl18, Kat20\]. |
| Population-specific divergence (PSD) | A measure of a target population’s genetic divergence from other selected populations \[Phi14\]. |
| Population substructure | Genetic differentiation among subgroups that can make allele draws more correlated than a pooled-population model assumes \[Bal94, Bal05b\]. |
| Porous and nonporous substrates | Surface classes that differ in how residue is retained and accessed by fingermark-development methods \[Bec20, Bec26d\]. |
| Positive predictive value (PPV) | The reliability of a positive category call in a specified validation setting \[Sch19\]. |
| PowerPlex Y23 | A commercial Y-STR multiplex with its own marker composition and rapidly mutating marker content \[Cou21, Ral21\]. |
| Prediction interval | A calibrated range intended to express uncertainty around an individual model prediction, when validated for the relevant use \[Nau23b, Ref23\]. |
| Presumptive test | A screening test that indicates a possible target and guides further examination \[Sij21\]. |
| Principal component analysis (PCA) | A method that summarizes major axes of variation and locates profiles relative to sampled references without directly giving probabilities of origin \[Kay23b\]. |
| Privacy impact assessment | A structured review of necessity, proportionality, access, secondary use, retention, disclosure, and safeguards \[Scu18\]. |
| Probabilistic genotyping | Statistical evaluation of DNA profile findings under competing propositions using models that account for uncertainty in genotype configurations \[Gil12, Gil21c\]. |
| Probabilistic-genotyping validation | Testing the scientific model, software implementation, and laboratory performance of a probabilistic-genotyping method for its intended use \[Cob16, Bri15b\]. |
| Process sequence | An ordered set of fingermark-development steps selected for an item; its value depends on substrate, residue, condition, and treatment history \[Sea12, Mar14f, Bec20\]. |
| Product rule | Multiplication of locus-specific genotype probabilities under linkage-equilibrium assumptions \[For03, Bal94\]. |
| Prosecutor’s fallacy | The error of treating the probability of evidence given a proposition as the probability of that proposition given the evidence \[Eve15, Gil18\]. |
| Proteomics | Analysis of proteins or peptides in a sample, including by mass spectrometry \[Ste12\]. |
| Prüm | A networked model for cross-border DNA-profile searching among national databases \[Ama19c, Too19\]. |
| PSA/p30 | A prostate-derived protein used as a marker associated with seminal plasma, but not exclusive to semen \[Gam20\]. |
| Pseudoautosomal region (PAR) | A region at the end of the Y chromosome that pairs and recombines with the corresponding X-chromosome region \[Cou21\]. |
| Public legitimacy | The perceived acceptability and trustworthiness of database practices, which cannot be inferred from match counts alone \[Mac19b\]. |
| Pull-up | An apparent signal in one dye channel caused by incomplete correction of fluorescence from another channel \[Sci21\]. |
| Purpose limitation | A governance principle that confines database use to its stated purposes \[Str19b, Ube24\]. |
| Pyrosequencing | A sequencing-by-synthesis readout that can quantify methylation at selected CpGs through nucleotide-incorporation signals \[Vid18, Fre20b\]. |
| qPCR | Real-time PCR monitored during amplification and used in forensic workflows to quantify DNA and assess selected sample-quality indicators \[Hud08, Ewi16\]. |
| Random-correspondence model | A model of how often a defined fingerprint feature configuration may arise among different-source impressions; it does not give the probability that a named person is the source \[Abr13\]. |
| Random-man-not-excluded (RMNE) | An inclusion statistic describing the share of a population not excluded by observed mixture alleles \[Gil06, Bie16f\]. |
| Random match probability (RMP) | A model-based estimate of the expected frequency of a DNA profile in a specified population under stated genetic assumptions \[For03, But24b\]. |
| Rapidly mutating Y-STR (RM Y-STR) | A Y-STR marker with a higher mutation rate that can distinguish some paternal relatives but may also differ between close relatives \[Bal14, Ral22\]. |
| Rare-haplotype problem | The difficulty of interpreting a haplotype observed rarely or not at all in a database when it may still occur in the population or be shared by relatives \[Bre10, And17b, And21b\]. |
| Recovery efficiency | The combined transfer of DNA from a sampled surface through collection and release into the extraction solution \[Bru24b\]. |
| Reference population | A sampled population used as a comparison in an ancestry analysis; unrepresented populations limit interpretation \[Tve22, Mog19\]. |
| Region of interest (ROI) | The image area believed to contain a latent fingermark and submitted for automated searching; some matchers require examiner marking of this region \[Cao17\]. |
| Relational genetic privacy | Privacy interests affecting relatives who may be identifiable or investigated through another person’s genetic data \[Ram18, Scu19b\]. |
| Repeatability and reproducibility | Agreement on repeated decisions by the same examiner and agreement among different examiners, respectively \[Ule12\]. |
| Restriction fragment length polymorphism (RFLP) | A method that distinguishes DNA fragments by length after restriction-enzyme digestion \[Roe13\]. |
| Retention | Continued storage and searchability of an included DNA profile under applicable rules \[Ama18\]. |
| Revised Cambridge Reference Sequence (rCRS) | The standard coordinate reference for reporting mitochondrial DNA sequence differences, not an ancestral or universal wild-type genome \[And99, Par14c\]. |
| Ridge-detail levels | Level 1 is overall pattern, Level 2 is minutiae, and Level 3 is pore and ridge-edge detail available in an impression \[Bec20, Bec22\]. |
| Ridge, furrow, and pore | A ridge is a raised skin band, a furrow is the lower area between ridges, and a pore is the surface opening of an eccrine duct \[Wer02, Glo23\]. |
| RMplex | An expanded research system combining rapidly mutating Y-STR markers to improve differentiation among male lines \[Ral21, Ral22\]. |
| Sanger sequencing | A chain-termination method for reading selected PCR-amplified DNA regions \[Cou21b, Car26b\]. |
| Score-based likelihood ratio | A measure obtained by modelling the probability density of a matcher score under competing propositions; the raw score alone is not an LR \[Neu20c\]. |
| Semenogelin (Sg) | A seminal-vesicle protein targeted by the RSID-Semen assay \[Gam20\]. |
| Semi-continuous model | A probabilistic-genotyping approach that models allele presence or absence and may account for drop-out and drop-in without directly modelling peak heights \[Gil12, Inm15\]. |
| Sensitivity | The ability of a test to return a positive result when its target is present \[Mor21b\]. |
| Sensitivity analysis | Examination of how changes in uncertain assumptions or inputs affect an evaluation \[Inm15, Tay18b\]. |
| Sequence-based allele nomenclature | A standardized way to describe STR alleles from their sequence, alignment, and repeat structure \[Par16, Get23\]. |
| Shared-match cluster | A grouping of genealogy matches that share matches with one another and may indicate a common ancestral line \[Kli21, Gre19\]. |
| Short tandem repeat (STR) | A short repeated DNA sequence used as a genetic marker in forensic profiling \[Had21\]. |
| Single-nucleotide polymorphism (SNP) | A genetic variant at one nucleotide position; dense SNP genotypes support comparisons with genealogy datasets \[But12j, Kli21\]. |
| Small-particle reagent (SPR) | A liquid suspension whose fine particles adhere to water-insoluble residue on wet or moist nonporous surfaces \[Bum16\]. |
| SNaPshot or minisequencing | A single-base-extension assay that measures selected methylation sites by capillary electrophoresis, with semi-quantitative peak ratios \[Vid18, Fre20b\]. |
| SNP microarray | An assay that genotypes a predefined set of SNP loci, with performance affected by DNA quantity and fragmentation \[Vri21\]. |
| Specificity | The ability of a test to return a negative result when its target is absent \[Mor21b\]. |
| Spectral calibration | Instrument-specific correction that separates overlapping fluorescence signals from different dye channels \[But12b\]. |
| Spectroscopy | Measurement of molecular spectral signatures, including Raman and FTIR, to characterize stains \[Sij21\]. |
| Spermatozoa | Male reproductive cells identifiable microscopically; their absence does not exclude the presence of seminal plasma \[Gam20\]. |
| Statistical cluster | A model-dependent grouping of sampled genetic data, not a natural or exhaustive human category \[Pri00c, Law18\]. |
| Stochastic threshold | A laboratory-validated signal level below which detected alleles carry increased risk of an undetected partner allele \[Gil12, Sci21\]. |
| STRUCTURE and ADMIXTURE | Model-based clustering methods that estimate cluster frequencies and individual membership or ancestry proportions \[Pri00c, Ale09\]. |
| Stutter | A secondary PCR product, commonly one repeat unit shorter than its parent allele, generated during STR amplification \[Wal96\]. |
| Sub-source proposition | A claim about who contributed the DNA represented in a profile \[Gil18\]. |
| Sufficiency decision | An examiner’s judgment that available comparison information permits a conclusion; an annotated feature count is not a universal threshold \[Ule14, Bec22\]. |
| Suitability for interpretation | A laboratory judgment about whether a DNA profile’s quality and information support a defensible interpretation or comparison \[Hic23, Sci21\]. |
| Targeted massively parallel sequencing | Parallel sequencing of selected SNP or other loci for a defined forensic task \[Til18, Nau17\]. |
| Targeted methylation assay | An assay measuring selected DNA-methylation sites or regions for a defined classification or prediction task \[Nau23b, Vid18\]. |
| Terms of service | Provider rules governing database use and law-enforcement matching; they may change and do not themselves establish legal authority \[Kli21, Ske20\]. |
| Tissue-specific differentially methylated region (tDMR) | A DNA region whose methylation patterns differ among specified tissues or cell types and may support tissue-source classification \[Vid18, Sij21\]. |
| Touch DNA | Low-level biological material recovered from an object after contact \[Toz22\]. |
| Trace | A remnant or sign of past presence or activity that may carry information about an event \[Rou22\]. |
| Transfer, persistence, prevalence, and recovery (TPPR) | Stages and contextual factors linking an activity to biological material recovered and observed \[Tay18, Oor19, Gil20\]. |
| Twin-differential methylated site (tDMS) | A candidate CpG showing a methylation difference between monozygotic twins; it is not by itself proof of trace attribution \[Vid17, Vid18\]. |
| Uniqueness | The claim that no other source has the same relevant characteristics; rarity alone does not establish uniqueness \[Col09\]. |
| Variable number tandem repeat (VNTR) | A DNA region containing a repeated sequence whose copy number varies among individuals \[Roe13\]. |
| Verification | A second examiner’s review that can identify overlooked detail or disagreement, but does not alone demonstrate that a conclusion is correct \[Ule14, Bec20\]. |
| Volar pad | A temporary fetal swelling of a developing digit that contributes to the setting in which friction-ridge patterns form \[Wer02, Kuc05\]. |
| Warm hit | A database match that may confirm a person already under investigation \[Ama19, Ama21\]. |
| Whole-genome sequencing (WGS) | Broad sequencing of prepared DNA fragments that can recover SNP data, subject to workflow and sample limits \[Kli21\]. |
| Y-chromosome haplotype reference database (YHRD) | A public reference resource containing submitted Y-STR and Y-SNP population data \[Wil15b, Roe20\]. |
| Yfiler | A commercial Y-STR multiplex used to generate male-lineage haplotypes \[Cou21\]. |
| Yfiler Plus | A commercial Y-STR multiplex with a marker set that includes rapidly mutating Y-STRs \[Cou21, Ral21\]. |
| Y-SNP | A single-nucleotide polymorphism on the Y chromosome used to characterize paternal-line variation \[Cou21, Kni22\]. |
| Y-STR database searching | Comparison of a Y-STR trace profile with stored male profiles to generate possible paternal-line investigative leads \[Ge20\]. |
| Y-STR haplotype | The set of STR variants observed together across a selected panel of linked Y-chromosome loci \[Kay17c, Cou21\]. |
| Y-STR reporting convention | The practice of stating markers, observed haplotype, comparison or propositions, reference data and method, and limits of a Y-STR conclusion \[Roe20, Reb20\]. |
